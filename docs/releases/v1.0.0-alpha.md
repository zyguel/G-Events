# G-Events v1.0.0-alpha Release Notes

Release date: May 12, 2026
Tag: v1.0.0-alpha

## Overview
This alpha release documents the current end-to-end feature set and operational scope for G-Events, consolidating the platform capabilities described across README and handoff documentation.

## Highlights
- End-to-end event lifecycle management (create, publish, register, check-in, report).
- Custom order forms with multi-section fields and JSONB storage.
- Ticketing, waitlists, and breakout sessions for event operations.
- Email campaigns and certificate delivery flows.
- Analytics and exports (CSV/XLSX/PDF).

## Features Included

### Event Management
- Create, edit, and publish events with banners, agendas, themes, and objectives.
- Per-event overview with status and scheduling controls.

### Registration and Order Forms
- Custom order forms for attendee registration.
- Waitlist support when event capacity is reached.

### Ticketing and Check-In
- Ticket types and capacity controls.
- QR-based check-in with manual lookup fallback.

### Communication and Certificates
- Email campaigns with scheduled processing.
- Certificate templates, issuance, and verification endpoint.

### Reporting and Analytics
- Per-event and cross-event analytics.
- Data export to CSV, XLSX, and PDF formats.

### Team and Security
- Role-based access control with organization scoping.
- Audit logging and tamper-evident certificate ledger.

## Known Scope Decisions
- Payment gateway and webhooks are intentionally excluded for the current deployment scope.
