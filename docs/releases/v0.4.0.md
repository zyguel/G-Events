# G-Events v0.4.0 Release Notes

Release date: March 30, 2026  
Tag: v0.4.0  
Issue: #24

## Overview
This release delivers major stability, security, and usability improvements across authentication, permissions, management workflows, notifications, translations, and event operations. It also introduces the organizer/attendee session-role flow and includes substantial backend hardening for API access control.

Compared to v0.2.0, this release includes:
- 31 commits
- 149 files changed
- 14,832 insertions
- 1,882 deletions
- Contributions from 4 contributors

## Highlights
- New role-selection authentication flow: users can choose organizer or attendee mode and switch between them.
- Permissions system reliability improvements, including active-organization aware permission resolution.
- Management fixes to prevent duplicate member invites for the same organization.
- Notification and header UX fixes, plus stricter organization scoping behavior.
- Significant API hardening and centralized security utilities.
- Translation architecture refinements and performance improvements.
- Audit system enhancements and off-chain integrity support.

## Migration Notes
- No explicit database migration is bundled in this release note file, but backend behavior around auth, permissions, and org scoping is stricter.
- Ensure environment configuration includes required Supabase variables (especially service-role usage where applicable).
- If custom roles appear under-scoped in existing environments, re-check active organization session selection and role-permission mappings.

## Known Considerations
- Tailwind class modernization hints may appear in local tooling (suggestions only, not release blockers).
- Role and permission visibility is now more sensitive to active organization context and session cookies by design.
