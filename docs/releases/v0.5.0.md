# G-Events v0.5.0 Release Notes

Release date: April 6, 2026  
Tag: v0.5.0 (planned)  
Compared against: v0.4.0

## Overview
v0.5.0 focuses on registration operations and attendee lifecycle workflows, with major additions to orders management, attendee check-in/ticket flows, and pagination scalability improvements across admin tables.

Compared to v0.4.0, this release includes:
- 10 commits
- 63 files changed
- 6,938 insertions
- 692 deletions
- Contributions from 3 contributors

## Highlights
- Added full registration and order-management flow enhancements (backend and CRUD workflows).
- Added QR-based ticket/check-in foundations and client ticket experience updates.
- Added pagination support to improve table scalability and usability in admin flows.
- Added admin feedback form support.
- Included targeted build/type reliability fixes before release.
- Expanded project/security documentation.

## What Changed vs v0.4.0
### Functional Comparison
- v0.4.0 emphasized authentication/session-role architecture, permission hardening, and API security foundations.
- v0.5.0 builds on that foundation by expanding day-to-day event operations: order lifecycle management, ticket/check-in flows, and higher-volume table handling through pagination.

### Operational Impact
- Better readiness for larger datasets due to pagination and table navigation improvements.
- Stronger organizer workflow continuity from order creation/review through ticket/check-in handling.
- Improved release stability via pre-release TypeScript/build fixes.

## Migration Notes
- No explicit database migration file is referenced directly in this release-note commit range.
- As with v0.4.0, ensure environment values used by auth, API, and Supabase integrations remain correctly configured before rollout.

## Known Considerations
- Tag `v0.5.0` is listed as planned in this note; create the tag at release time.
- Commit messages indicate some features are marked partial during implementation; verify QA sign-off for all related user flows before production rollout.
